# Local advisor enabled
Run `python ./cli/advisor_enabled.py --enabled <USER_INTENT> --workspace <PROJECT_ROOT>` from the installed plugin root. Accept true/false, yes/no, enabled/disabled, on/off, engage/disengage; copy stdout verbatim.
