# Local critic model

Run `uv run --no-project python ./cli/critic_model.py --model "<USER_SELECTION>" --workspace <PROJECT_ROOT>`. Without a selection, print the current model and picker. The choices are Auto, Cursor Grok 4.6, Composer 2.5, Gemini 3.7 Flash, GPT-5.4-Nano, and Kimi-K3; Cursor controls effort defaults.
